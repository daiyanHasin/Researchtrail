# User stories

Written for the primary user, a student researcher. Status refers to this draft.

| # | As a student researcher, I want to… | So that… | Done when… | Status |
|---|---|---|---|---|
| 1 | open a project by choosing a folder | everything stays in files I own | a `.trail/` folder appears; no account asked | Done |
| 2 | add a paper by pasting any free link | I never download or upload files | a card appears; the source is not on disk | Done (verify on real links: spike A) |
| 3 | upload a PDF when no free link exists | my library is complete | the PDF becomes a card and is not kept | Done |
| 4 | see each paper as a card | I don't reread papers to remember them | every item shows the sentence it came from; wrong items can be removed | Done |
| 5 | ask "which papers use SMOTE?" | I find answers without rereading | results show paper and section and link to the card | Done |
| 6 | keep my messy file names and no git | I don't change my habits | `draft1.py` and `draft_final.py` appear as one history | Done |
| 7 | see what changed in plain words | I understand why results changed | "learning_rate 0.001 → 0.0005; added SMOTE" plus the diff | Done |
| 8 | restore an old version | I can undo a bad change | the old version is written back; the current one is saved first | Done |
| 9 | see what each paper did next to what I did, per stage | I know where I match or differ | a matrix with papers + Mine and evidence on every dot | Done |
| 10 | have my row drafted from my code | I don't describe my work by hand | Mine lists techniques with file, line and function | Done |
| 11 | correct my row and teach it new steps | the comparison stays trustworthy | remove, put back, add by hand, name unknown steps | Done |
| 12 | improve a card with my free chat | cards get better without paying | pasted JSON is checked; unsupported claims are set aside | Done |
| 13 | copy a prompt for "improve my feature engineering" | a free chat gives grounded help | the pack fits the chosen budget and cites papers and files | Done |
| 14 | move my project to another computer | I never lose work | copying the folder keeps cards, links, history and notes | Done |
| 15 | link code to a specific paper passage by hand | I can cite the exact source of a step | a manual link shows on the card and in Compare | Next |
| 16 | log my run results next to the paper's | I see whether I reproduced it | reported vs mine table per metric | Next (v1.1) |
